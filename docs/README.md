# PYCMD


To work You need:


* Windows 11/Windows 10
* Rich module: 14.2.0 (to animations)
* stdiomask: 0.0.6 (to masked passwords)
* Python 3.13.4 or higher
* pip 25.3 or higher

### To install all packages type in PowerShell at PyCMD folder: pip install -r .\requirements.txt

## Info:
### Mod name can't has space in it
